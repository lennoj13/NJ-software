# NJ Software

> **Suite de Software Independiente, Linux Dots, Android OS Apps y Directorio de Proyectos**

Plataforma web oficial de **NJ Software**, desarrollada por [Jonnel Anchundia (@lennoj13)](https://github.com/lennoj13). Reúne el catálogo de aplicaciones, extensiones de navegador, dotfiles para Linux y un directorio interactivo sincronizado en tiempo real con la API de GitHub.

---

## ✨ Proyectos Destacados en la Suite

- **NJ Dock (Chrome Extension MV3):** Barra dock flotante interactiva y minimalista para navegadores web con acceso rápido a marcadores, atajos globales y selector de pestañas activas.
- **NJ Plasma Dots & Linux Suite:** Dotfiles reproducibles, temas de precisión, scripts de autoinstalación y optimizaciones de compositor para KDE Plasma 6 y Wayland.
- **NJ Car Launcher & Android OS Suite:** Interfaz táctil modular para radios y tablets de automóvil con soporte de audio en segundo plano, muelle de navegación GPS y modo día/noche.
- **Directorio de Proyectos GitHub Live:** Conexión en vivo con la API pública de GitHub para mostrar repositorios, últimos commits y versiones de forma automática.

---

## 🛠️ Stack Tecnológico

- **Framework:** [React](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Estilos:** [Tailwind CSS](https://tailwindcss.com/) (Glassmorphism & diseño técnico neutral)
- **Iconos:** [Lucide React](https://lucide.dev/)
- **Integración:** GitHub REST API v3 con caché local resiliente

## 🚀 Puesta en Marcha

### Prerrequisitos
- Node.js 18+ y npm

### Instalación y Desarrollo
```bash
# Clonar repositorio
git clone https://github.com/lennoj13/NJ-software.git
cd NJ-software

# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev
```

### Compilar para Producción
```bash
npm run build
```
